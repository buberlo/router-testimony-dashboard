# Router Testimony

> Your home network testifies about who was really online.

A web dashboard turns household device activity into courtroom testimony when someone claims they were offline. Each device has a credibility score and can be cross-examined with bandwidth, battery, and connection clues. You can bribe a device with fake bandwidth to produce a contradictory story.

## Features
- Device witness timeline with credibility scores and connection history
- Cross-examine devices using bandwidth, battery, and online-status clues
- Bribe a device with fake bandwidth to generate a conflicting testimony
- Export a printable transcript with timestamps and confidence levels

## Stack
- Next.js
- Postgres
- WebSockets
- Recharts

## Getting started
```
npm install, create .env with DATABASE_URL, start Postgres and run migrations, then npm run dev
```
